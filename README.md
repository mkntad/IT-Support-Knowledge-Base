## Quick Reference

### Tier 1 Support Checklist
- [ ] Gather detailed information (error messages, when issue started, steps already taken)
- [ ] Verify user account status in Active Directory
- [ ] Check relevant logs (Event Viewer, application logs)
- [ ] Attempt basic troubleshooting (restart, clear cache, etc.)
- [ ] Escalate if necessary with full documentation

### SLA Response Times (Example)
| Severity | Response Time | Resolution Time |
|----------|---------------|-----------------|
| Critical | 15 min        | 1 hour          |
| High     | 30 min        | 4 hours         |
| Medium   | 1 hour        | 1 day           |
| Low      | 4 hours       | 3 days          |

## How to Use This Guide

1. **Search by issue category** using the table of contents
2. **Follow step-by-step instructions** for troubleshooting
3. **Note any error messages** encountered for reference
4. **Escalate if:** Steps don't resolve the issue after 2 attempts
5. **Document everything** in the ticketing system

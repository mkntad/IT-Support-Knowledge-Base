 # IT Support Escalation Flowchart

User reports issue
↓
Does issue exist in knowledge base?
├─ YES → Follow SOP
│ ↓
│ Try Steps 1-3
│ ↓
│ Issue resolved?
│ ├─ YES → Document in ticket, close
│ └─ NO → Go to "Escalate to L2"
│
└─ NO → Document issue, add to knowledge base, escalate to L2

Escalate to L2
↓
Provide:
-User details
-Exact error messages (screenshots)
-Steps already taken
-Relevant logs
